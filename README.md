# Book of Hours helper
This repo is my attempt at a helper for a 1st time playethrough of Book of Hours.
This can show spoilers if you are not carefull.

## Known Bugs
Clearing lines breaks horribly if text goes past the edge of the terminal.


## Building
Use `npm run clean`, `npm run build`, and `npm run package` to create/package an executable.

NOTE: there's a known bug with "pkg".
If you get a `Failed to make bytecode node20-x64 for file [...] error (write EOF)` error, restart your computer.
It seems pkg only works once and then breaks.
restarting your computer should fix it.
